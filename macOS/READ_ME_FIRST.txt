ATPL Air Law Quiz - macOS launchers
===================================

Double-click clicktostart.command to start the quiz.

The Terminal app will open and start a small local web server.
Your default browser will open at http://localhost:8000/index.html

Keep the Terminal window open while using the quiz.
To stop the quiz, close the Terminal window or press Ctrl+C inside it.

If macOS shows a security warning the first time:
  - Option A: Right-click clicktostart.command -> Open -> Open.
  - Option B: Open Terminal in this folder and run once:
        chmod +x clicktostart.command
    Then double-click clicktostart.command again.

clicktostart.sh is a Linux / Terminal-only version of the same launcher.
