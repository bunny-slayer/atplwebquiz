ATPL Air Law Quiz - Windows launchers
=====================================

Double-click ONE of the files in this folder to start the quiz:

1. clicktostart.bat
   Use this if Python is already installed on your computer.

2. install_python_then_start.bat
   Use this if you do NOT have Python, or you are not sure.
   It will install Python first, then launch the quiz.

After it starts, your default browser will open at
http://localhost:8000/index.html

Keep the black command-prompt window open while using the quiz.
To stop the quiz, close that window or press Ctrl+C inside it.
